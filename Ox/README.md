# Ox code — estimation and forecasting

MCMC estimation and rolling one-step-ahead forecasting of the (R)SV models.
All files live flat in this directory so that `#include<RSVAZ.ox>` resolves and
`loadmat("../Data/...")` points at the sibling `Data/` folder.

**Run from this directory:** e.g. `oxl rsv_gh_st_n225_prediction.ox`
(or `oxl -i. <script>.ox`). Forecast output is written to a per-index folder
(e.g. `N225_prediction/`) that is git-ignored and regenerated by the run.

## Model classes

| File              | Model family                                    | Distributions (flags)                         |
|-------------------|-------------------------------------------------|-----------------------------------------------|
| `RSVAZ.ox/.h`     | Realized SV, Azzalini skew-t                    | N / T / AZ-SN / AZ-ST via `SetDist(fls,flt)`  |
| `SVAZ.ox/.h`      | SV, Azzalini skew-t                             | same                                          |
| `RSVGH.ox/.h`     | Realized SV, generalized-hyperbolic skew-t      | GH-ST                                         |
| `SVGH.ox/.h`      | SV, generalized-hyperbolic skew-t               | GH-ST                                         |
| `RSV_skewFS.ox/.h`| Realized SV, Fernández–Steel skew-t             | FS-SN / FS-ST via `SetIsT`/`SetIsSkew`        |
| `ReportMCMC.ox/.h`| MCMC output summary helper (used by `RSV_skewFS`)|                                              |

Measurement (log-RV) equation: `x_t = xi + psi * h_t + u_t`. The slope `psi` is
fixed at 1 in the baseline; the `*_psi_*` scripts estimate it (see below).

## Rolling forecast scripts

- `rsv_{az_n,az_sn,az_st,gh_st}_{djia,n225}_prediction.ox` — RSV models, main sample.
- `sv_{az_sn,az_st,gh_st}_{djia,n225}_prediction.ox`        — SV counterparts.
- `*_n225_prediction_2020.ox`                               — COVID-period sample (N225).
- `*_djia_prediction_2020.ox` (2026 revision)                — COVID-period sample (DJIA), 15
  models, mirroring N225's COVID-period coverage: RSV with psi fixed at 1
  (`rsv_az_{n,sn,st,t}`, `rsv_gh_st` — 5, baseline), RSV with psi free
  (`rsv_az_{n,sn,st,t}_psi`, `rsv_gh_st_psi` — 5, sensitivity; the AZ-family
  psi variants were added 2026-07-16 to match N225, which already had all 5 —
  previously only `rsv_gh_st_psi` existed for DJIA), and SV (`sv_az_{n,sn,st,t}`,
  `sv_gh_st` — 5; SV has no psi concept, it only uses returns, not the log-RV
  measurement equation, same as N225). Duplicated from the N225 2020 scripts
  (`nprd=253`, NYSE 2020 trading days, vs. N225's 242; reads
  `../Data/DJIA_rcc_rv5_rkth2_bv_medrv_2012_2020_tick.csv`
  — **close-grid** convention, same as the main-sample DJIA scripts above. An
  open-grid variant matching N225's actual construction was tried 2026-07-10
  but reverted 2026-07-16 per Watanabe-sensei: using a different grid for the
  COVID period than the main sample would be internally inconsistent, so DJIA
  stays close-grid throughout and N225 stays open-grid — the cross-index
  mismatch is accepted and documented as a limitation instead).
  Launch all 11 with `./run_djia_2020.sh` (background, one process per model);
  after estimation finishes, run `./organize_djia_2020_output.sh` once before
  merging (the merge scripts expect `DJIA_prediction_2020/files/`, but the
  per-window output lands directly in `DJIA_prediction_2020/`).
- Fernández–Steel: `RSV_skewFS_run_emp.ox` (single estimation),
  `RSV_skewFS_run1.ox` (parallel-prediction template; replicate with
  `copy_oxfile.sh`, launch with `runpred.sh`).

A single `rsv_*` / `sv_*` file selects the distribution through the flags
`fls`/`flt` (Azzalini) or by class (GH, FS); see the header of each file.

## Free-`psi` extension (revision: Comment 2)

Estimates the log-RV slope `psi` instead of fixing it at 1, as a
sensitivity/robustness analysis. Enabled with `SetBC(1)` (AZ/GH classes) or
`SetIsPsi(1)` (FS class).

- `rsv_{n,t,sn,st}_psi_{djia,n225}_prediction.ox` (AZ family; named `rsv_az_*_psi_*`) — main sample only.
- `rsv_gh_st_psi_{djia,n225}_prediction.ox` — main sample.
- `rsv_az_{n,sn,st,t}_psi_n225_prediction_2020.ox`, `rsv_gh_st_psi_n225_prediction_2020.ox`
  — COVID-period sample (N225), 5 models (mirrors the main-sample psi set
  exactly, `nprd=242`). Not yet run on real data as of 2026-07-11 (validated
  on simulated data, recovers `psi ≈ 1.25`). Launch with `./run_n225_2020_psi.sh`
  (5 background processes). A DJIA COVID-period counterpart does not exist yet.
- `RSV_skewFS_run_psi_n225_2020_{st,sn}.ox` — COVID-period FS-ST/FS-SN (N225).
  The main-sample DJIA FS runs use this project's own parallel-chunk
  convention (`RSV_skewFS_run<N>.ox`, `N=1..11`, each inferring its window
  range from its own filename via `oxfilename`); these COVID-period psi-free
  scripts instead run as a **single sequential process** over all 242
  windows (changed 2026-07-11, to match how the AZ/GH COVID-period scripts
  run — simpler, one core instead of eleven). `RSV_skewFS.ox` gained a new
  `"Nikkei-RV-2020"` (and `"DJIA-RV-2020"`, close-grid, for later DJIA use)
  data branch for this — additive, existing branches unchanged. 
- `RSV_skewFS_run_psi.ox` — main sample (DJIA), 11-way parallel split.

Validated on simulated data (true `psi = 1.25` is recovered).

## Simulation study

`rsv_{az_n,az_sn,az_st,az_t,gh_n,gh_st}_simulation.ox` — generate data from
known parameters and check posterior recovery.

## Merging forecasts

`merge_prediction_results_{az,gh}.ox` and the `_2020` variants collect the
per-window forecast files. The `_2020` variants loop over `sdata =
{"DJIA","N225"}` with the correct `nprd` per index (253 / 242). (The R script
`R/merge_prediction_results_2026.R` performs the consolidated merge used for
the final tables; `R/merge_prediction_results_djia_2020.R` is the COVID-period
DJIA counterpart.)

## Requirements

Ox 8.x (Console/Professional). Packages used: `oxstd`, `oxprob`, `oxfloat`,
`oxdraw`, and `maximize` (Fernández–Steel only).

## Recomputation of the Azzalini forecasts (`az_recomputation/`, 2026-09/10)

The one-day-ahead forecasting step of `RSVAZ.ox` / `SVAZ.ox` standardized the truncated-normal
leverage term by `sqrt(1-c^2)` instead of `sqrt(1-delta^2)` (fixed in the classes above on
2026-09-26). To measure the effect and regenerate every Azzalini forecast of the article, the
20 series (SV/RSV-AZ-SN/ST x DJIA/N225 x main sample / 2012-2020 sample, plus the free-psi
RSV variants over 2012-2020; 7,742 rolling windows) were re-estimated with the *dual* classes in
`az_recomputation/`, which compute both the original and the corrected forecast from the same
posterior draws and random numbers and save the per-draw state (`pstate_*.csv`).

- `az_recomputation/RSVAZ.ox`, `SVAZ.ox` (+ `.h`): dual-output versions of the classes. Output per
  window: `h1_y_*.csv` = [h1 y1 (fixed), h1 y1 (orig)], `var_orig_*`, `es_orig_*`, `volf_orig_*`,
  `pstate_*`.
- `az_recomputation/azdual_<sample>_<model>_c<k>.ox`: the 118 driver scripts (one per series and
  window chunk; `_psi_` = free psi). Run from `az_recomputation/` with `oxl <driver>.ox`; data are
  read from `../../Data/` via the same relative paths as the main drivers.
- `az_recomputation/tools/`: the Python scripts used to collect, check and compare the runs
  (`azdual_aggregate.py` builds the per-series aggregates read by the R merge scripts under
  `RSVST_AZ=dualfixed`; `azdual_compare.py` produces the series-by-series comparison; `mcmc_diag.py`
  implements the diagnostics; `azconfirm_check.py` / `azconfirm_pool.py` apply the multi-chain
  acceptance rules of Section 5.2 of the Supplementary Material and pool accepted chains). They
  assume the directory layout of the original working directory (see the `--help` of each script);
  thresholds are the ones stated in the Supplementary Material.
