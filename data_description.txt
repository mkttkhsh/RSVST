Data description (public repo)

- This repository does NOT contain proprietary high-frequency data.
- Variables expected for real-data runs (example):
  * date (YYYYMMDD)
  * rcc  : close-to-close return
  * rv   : Realized Variance (5-min sampling; non-trading hours removed)
  * rk   : Realized Kernel (Parzen kernel)

The empirical data are licensed (e.g., Oxford Realized Library) and cannot be redistributed.
Users with access can point the runner to their local directory via:
  --mode=real --data_dir=/path/to/realdata
